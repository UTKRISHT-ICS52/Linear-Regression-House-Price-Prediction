# Linear-Regression-House-Price-Prediction

## Overview
This project implements a Linear Regression model to predict house prices using Python and Scikit-learn.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Load and explore the dataset.
2. Separate input features and target variable.
3. Split data into training and testing sets.
4. Train the Linear Regression model.
5. Generate predictions.
6. Evaluate the model using regression metrics.
7. Visualize actual versus predicted values.

## Model Performance

| Metric | Result |
|---|---:|
| R² Score | 0.6688 |
| MAE | 3.1891 |
| MSE | 24.2911 |
| RMSE | 4.9286 |

## Conclusion
The Linear Regression model explains approximately 66.88% of the variance in the target variable on the test set.

## How to Run
1. Install the required libraries using `pip install -r requirements.txt`.
2. Open `Linear_Regression.ipynb` in Jupyter Notebook.
3. Run the notebook cells sequentially.
